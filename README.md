# Dog movement Analysis
The repository houses data, scripts and knitted files for the analysis of free-ranging dog movement from Mudumalai Tiger Reserve, India. 
The folder *Telemetry data* houses the data used in the analysis and the analysis scripts and results are in the repository. The folder *Figs* have the final figures used in the manuscript or supplementary files.
